# Contributing to DataDriven-Walkability

We welcome contributions from urban data scientists, geospatial analysts, and city planners. As this project scales to process 400+ global metropolitan areas, community input is vital.

## How to Contribute
1. **Bug Reports & Feature Requests:** Use the GitHub Issue Tracker to report computational bottlenecks or suggest new spatial indicators.
2. **Code Contributions:** 
   * Fork the repository.
   * Create a new branch for your feature (`git checkout -b feature/new-spatial-metric`).
   * Ensure your code adheres to standard Python PEP 8 guidelines.
   * Submit a Pull Request (PR) detailing the changes and any dependencies (e.g., updates to OSMnx or GeoPandas).

## Codex for Open Source Integration
This repository leverages AI-assisted maintainer workflows. Pull requests and issue triaging may be reviewed using OpenAI Codex and ChatGPT Pro to ensure high-quality, scalable code integration.

## Roadmap Contributions
Once the v2.0 HPC processing scripts clear peer review, we will actively seek contributors to help engineer automated extraction systems for global bounding boxes and to integrate General Transit Feed Specification (GTFS) timetables for multimodal routing.
