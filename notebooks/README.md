# Spatial Analysis Notebooks (v1.0)

This directory contains the computational pipeline utilized for the study of Southeast Asian megacities. 

## Contents
* `walkability_isochrones_sea.ipynb`: The primary script for extracting pedestrian street networks and points of interest via the OSM API, integrating WorldPop rasters, and generating the hexagonal spatial index.
* `maup_sensitivity_analysis.ipynb`: The scripts used to compute the 13 walkability indicators and perform the multi-scale sensitivity analysis across 400m, 800m, and 1200m spatial boundaries.
