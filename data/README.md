# Processed Spatial Datasets

Due to GitHub's file size limitations, large GPKG files and raw geometries are hosted externally.

## 1. Southeast Asia Baselines (v1.0)
The complete processed datasets for Jakarta, Manila, Ho Chi Minh City, and Phnom Penh (evaluating network connectivity, topography, and amenity density) are permanently archived and openly available via Zenodo.
* **Zenodo Repository:** `[https://zenodo.org/records/19966079]`

## 2. Monterrey, Mexico Sample (v2.0 Preview)
The `/monterrey_sample` folder contains a subset of the output generated by our upcoming HPC pipeline. 
* **Data Included:** Continuous 50m to 250m hexagonal spatial grids containing 15 spatial predictors (intersection density, distance to amenities, cul-de-sac ratios). 
* **Usage:** This data directly feeds the Recommender Intervention Model (RIM) and the Tableau visual analytics dashboard.
